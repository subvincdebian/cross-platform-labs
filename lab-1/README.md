# CyberClub - Застосунок для кіберспортивного клубу (Лабораторна робота № 1.2)

Кросплатформний вебзастосунок для відвідувачів та адміністраторів кіберспортивного клубу, розроблений у межах курсу **"Крос-платформне програмування"**.

## 📌 Структура проєкту

```text
cross-platform-lab/
├── index.html   # Семантична розмітка та структура вебсторінки клубу
├── style.css    # Адаптивні стилі в темній геймерській темі (Flexbox + Media Queries)
├── script.js    # Логіка бронювання місць та збереження у LocalStorage

```

---

## 🚀 Функціонал застосунку

1. Онлайн-бронювання місць у різних ігрових зонах клубу (Standard, VIP, Boot Camp, PS5).
2. Збереження історії та активних сесій у локальному браузерному сховищі (`localStorage`).
3. Повна адаптивність під десктопні монітори та мобільні пристрої (`@media (max-width: 600px)`).
4. Архітектурна готовність до пакування у мобільний застосунок через WebView (Capacitor/Cordova) та десктопний клієнт (Electron/Tauri).

---

## 🛠 Запуск проєкту локально

1. Відкрийте файл `index.html` у будь-якому браузері (Chrome, Edge, Firefox, Safari).
2. Або запустіть у WebStorm (клік правою кнопкою на `index.html` -> **Open in Browser**).
