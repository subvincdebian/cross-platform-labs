## 1. Стек технологій та архітектура
- **Фреймворк:** React 19 (Hooks: `useState`, `useEffect`, `useMemo`)
- **Збирач:** Vite 6 + TypeScript 5.7+
- **Стилізація:** Tailwind CSS v4 (@tailwindcss/vite)
- **Іконки:** Lucide React
- **Архітектура:** Feature-Sliced Design (FSD)
- **Сховище:** LocalStorage API (із захистом через try/catch)

---

## 2. Структура Feature-Sliced Design (FSD)
```
lab-4/
├── src/
│   ├── app/                      # Ініціалізація застосунку та глобальні стилі Tailwind
│   │   ├── App.tsx
│   │   └── index.css
│   ├── pages/                    # Композиція сторінок
│   │   └── club-bookings/        # Головна сторінка бронювань (CyberClubPage)
│   ├── widgets/                  # Комплексні блоки інтерфейсу
│   │   ├── header/               # Шапка клубу з логотипом та живими лічильниками
│   │   ├── booking-form/         # Форма створення бронювання з валідацією
│   │   └── booking-list/         # Список карток бронювань із порожніми станами
│   ├── features/                 # Бізнес-фічі користувача
│   │   └── filter-bookings/      # Пошук за нікнеймом, фільтрація за зонами та статусом
│   ├── entities/                 # Бізнес-сутність предметної області
│   │   └── booking/              # Типи Booking, модель та UI-картка BookingCard
│   ├── shared/                   # Перевикористовувані утиліти та UI-компоненти
│   │   ├── config/               # Конфігурація ігрових зон, тарифи, ключі
│   │   ├── lib/                  # Утиліти safe load/save для localStorage
│   │   └── ui/                   # Кнопки, інпути, селекти, бейджі, алерти
│   ├── index.html
│   ├── package.json
│   ├── tsconfig.json
│   └── vite.config.ts
```

## 3. Інструкція із запуску

### Встановлення залежностей:
```bash
npm install
```

### Запуск у режимі розробки:
```bash
npm run dev
```
Після запуску застосунок доступний за адресою: `http://localhost:5173/`

### Збірка для продакшну:
```bash
npm run build
```

## 4. Чек-лист тестування сценаріїв роботи (Завдання 12)

1. **Спроба додати з порожнім полем:**
   - Очистіть поле нікнейму гравця та натисніть «Додати бронювання».
   - Виводиться червоне сповіщення «Введіть нікнейм гравця!». Бронювання не додається.

2. **Успішне додавання:**
   - Введіть нікнейм, оберіть ігрову зону, дату, тривалість та місце.
   - Натисніть «Додати бронювання».
   - Виводиться зелене сповіщення «Бронювання успішно додано!», форма очищується, лічильник «Всього» збільшується.

3. **Зміна стану виконання:**
   - Натисніть кнопку «Виконано» на картці бронювання.
   - Стан змінюється на зелений бейдж «Виконано», текст закреслюється, збільшується лічильник «Виконано».
   - Натискання «Відновити» повертає статус в «Активне».

4. **Видалення бронювання:**
   - Натисніть кнопку «Видалити» на картці.
   - Бронювання миттєво видаляється зі списку, оновлюються лічильники шапки та каса.

5. **Пошук та фільтрація на льоту:**
   - Введіть частину нікнейму у поле швидкого пошуку — список фільтрується в реальному часі.
   - Натисніть фільтри «Активні» або «Виконано» — відображаються лише відповідні записи.
   - Виберіть конкретну зону в селекті (наприклад, VIP Lounge) — відображаються записи лише цієї зони.

6. **Збереження у LocalStorage:**
   - Додайте нове бронювання або змініть статус.
   - Оновіть сторінку в браузері (F5).
   - Всі внесені дані залишаються збереженими без втрати.

7. **Адаптивність інтерфейсу:**
   - Зменшіть ширину вікна браузера або увімкніть DevTools Device Mode (<600px).
   - Елементи форми та карток автоматично адаптуються в одну вертикальну колонку без горизонтального скролу.
