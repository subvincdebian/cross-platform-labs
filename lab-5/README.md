## 1. Стек технологій та архітектура
- **Фреймворк:** React Native (0.88+) + Expo SDK 58 (Expo Go)
- **Мова:** TypeScript (строгий режим, path alias `@/*`)
- **Компоненти React Native:** `View`, `Text`, `TextInput`, `TouchableOpacity`, `FlatList`, `StyleSheet`, `Alert.alert`, `StatusBar`
- **Безпечна зона екрана:** `react-native-safe-area-context` (`SafeAreaProvider`, `SafeAreaView`)
- **Архітектура:** Pure Feature-Sliced Design (FSD)

## 3. Інструкція із запуску проєкту

### Встановлення залежностей:
```bash
npm install
npx expo install react-native-safe-area-context
```

### Запуск сервера розробки Expo:
```bash
npm start
```
Або:
```bash
npx expo start
```
Якщо локальна Wi-Fi мережа блокує прямі з'єднання між комп'ютером і смартфоном:
```bash
npx expo start --tunnel
```

### Відкриття застосунку:
1. **На фізичному смартфоні (Android / iOS):**
   - Встановіть застосунок **Expo Go** з Google Play або App Store.
   - Відскануйте QR-код з терміналу:
     - На Android: через функцію сканування у застосунку Expo Go.
     - На iPhone: стандартною камерою iOS (відкрити в Expo Go).
2. **В емуляторі Android (Android Studio):** натисніть клавішу `a` у терміналі.
3. **У симуляторі iOS (macOS Xcode):** натисніть клавішу `i` у терміналі.

*Примітка:* Застосунок не призначений для web-версії (клавіша `w`), оскільки нативні системні модальні вікна `Alert.alert` коректно працюють виключно на нативних платформах Android та iOS.

## 4. Покроковий сценарій перевірки (відповідно до методички)

1. **Крок 1. Загальний вигляд застосунку:**
   - Відображається шапка з заголовком "CyberClub Mobile" та статистикою "Усього бронювань: 2 · Виконано: 1".
   - Картка форми "Додати бронювання" з полем нікнейму, кнопками вибору зон, числовими полями ПК та годин гри і кнопкою "Додати бронювання".
   - Картка списку бронювань із панеллю фільтрації та пошуку, що займає вільний простір екрана (`flex: 1`). Вміст не заходить під системні вирізи завдяки `SafeAreaView`.
2. **Крок 2. Перевірка порожнього поля (валідація):**
   - Натисніть кнопку "Додати бронювання" з порожнім полем або якщо введено лише пробіли.
   - З'являється системне вікно `Alert.alert("Помилка", "Будь ласка, введіть нікнейм гравця.")`.
   - Запис до списку не додається.
3. **Крок 3. Додавання бронювання:**
   - Введіть нікнейм (наприклад, "NiKo"), оберіть зону "VIP Lounge", натисніть "Додати бронювання" або кнопку "Done" на клавіатурі.
   - З'являється вікно `Alert.alert("Успіх", "Бронювання успішно додано.")`.
   - Нове бронювання додається першим у список, поле очищується, лічильник "Усього" збільшується.
4. **Крок 4. Позначення бронювання виконаним (toggle):**
   - Торкніться картки бронювання в списку.
   - Текст нікнейму стає закресленим (`textDecorationLine: "line-through"`), фон змінюється з блакитного на зелений, а статус змінюється на "Виконано".
   - Лічильник виконаних сесій збільшується на 1. Повторний дотик повертає картку до попереднього активного стану.
5. **Крок 5. Видалення бронювання:**
   - Натисніть червону кнопку "Видалити" біля картки.
   - З'являється діалог підтвердження `Alert.alert("Видалення", ...)`.
   - Після підтвердження запис зникає зі списку, а лічильники зменшуються.
   - Якщо видалити всі записи, замість списку відображається текст: "Бронювань поки немає. Додайте перше!".
6. **Крок 6. Прокручування та клавіатура:**
   - При додаванні великої кількості записів `FlatList` плавно прокручується всередині нижньої картки, а форма вгорі залишається зафіксованою на екрані.
   - Завдяки `keyboardShouldPersistTaps="handled"` взаємодія з елементами списку доступна навіть при відкритій клавіатурі.
7. **Крок 7. Перевірка Fast Refresh:**
   - Змініть текст заголовка у файлі `src/widgets/header/ui/Header.tsx`, наприклад додавши своє ім'я: "CyberClub Mobile - Міхал".
   - Збережіть файл — інтерфейс на пристрої миттєво оновить заголовок без перезавантаження та втрати стану.
